# 🔦 МИШУТКА: Протокол «Тишина»

**2D хоррор-платформер про психбольницу №6.** Ты — Мишутка. Ты очнулся в палате, привязанный ремнями, и ничего не помнишь. По всей больнице спрятаны 8 записок — их писал ты сам, пока ещё помнил. Найди их. Вспомни. Выживи. И бойся главврача… **Тамика**.

Никаких внешних ассетов: вся графика рисуется кодом на Canvas, весь звук синтезируется через WebAudio. Просто открой файл — и играй.

## ▶ Как запустить

Вариант 1 — напрямую: открой `index.html` в браузере (Chrome / Edge / Firefox).

Вариант 2 — через локальный сервер:

```bash
cd horr
python3 -m http.server 8080
# открыть http://localhost:8080
```

Проверка логики (smoke-тест, Node.js):

```bash
node test/smoke.js
```

## 🎮 Управление

| Клавиша | Действие |
|---|---|
| **A / D** или **← / →** | движение |
| **Space / W** | прыжок (держи — выше; **S + прыжок** — спрыгнуть с полки) |
| **Shift** | бег (тратит выносливость) |
| **Мышь** | фонарь и прицел — фонарь **в руке Мишутки** |
| **ЛКМ / J** | атака |
| **E** | обыскать / взять / открыть / читать |
| **F** | вкл/выкл фонарь |
| **1 / 2 / 3 / 4** | руки / нож / пистолет / затычка |
| **R** | перезарядить пистолет |
| **Q** / **T** | аптечка / пилюли |
| **Esc / P** | пауза, **M** — звук |

Есть сенсорное управление для телефонов.

## 🕯 Что в игре

- **Катсцена с 3D-элементами** — побег-коридор на CSS-3D, дождь, сирены, печатная машинка: как Мишутка попал в больницу.
- **Сюжет на 8 записках** — с твистом и **двумя концовками** («Пробуждение» и «Тишина»).
- **Больница из 9 зон**: Приёмный покой, Палата №1, Процедурная, Изолятор, Архив-Морг, кабинет Тамика… Шкафчики, тумбочки, койки, каталки, морозильники — всё обыскивается (а в одном шкафу — засада).
- **5 видов призраков** — порождений стираемой памяти: Шептун, Плакальщица, Смирительный, Ползун и твой **Двойник**. Плюс босс — **главврач Тамик** в 3 фазах.
- **Фонарь** — светится из руки героя, следует за мышью. Тени **боятся света**: подсвеченный призрак получает +50% урона.
- **Три шкалы**: здоровье, выносливость, **рассудок**. Во тьме и рядом с тварями рассудок тает: шёпот, глитчи, силуэты-галлюцинации.
- **Оружие**: кулаки → нож → пистолет (патроны ищи в шкафчиках) → **затычка-отмычка** для замков.
- **Живой портрет** слева снизу: лицо Мишутки реагирует на раны, усталость и безумие.
- **Процедурный звук**: гул больницы, сердцебиение, шёпот, вопли, гром за окном.
- **Автосохранения**: зашёл в новую палату — прогресс записан. Кнопка «Продолжить» в меню.

## 📁 Структура

```
index.html      — разметка, HUD, меню, катсцена
css/style.css   — весь визуал интерфейса + 3D-коридор
js/audio.js     — синтез звука (WebAudio, без файлов)
js/data.js      — сюжет, записки, уровень, баланс
js/engine.js    — ввод, камера, частицы, свет/тьма
js/entities.js  — Мишутка, призраки, босс, мебель, двери
js/game.js      — игровой цикл, рендер, HUD, сохранения
test/           — smoke-тест (node test/smoke.js)
```

## ⚠ Предупреждение

Игра содержит мигающий свет, громкие звуки и скримеры. Не рекомендуется при эпилепсии. Наушники — рекомендуются. Выключать фонарь — нет.
